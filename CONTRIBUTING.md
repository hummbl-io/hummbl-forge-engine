# Contributing to hummbl-forge-engine

Thank you for considering contributing to hummbl-forge-engine.

---

## Pull Request Process

1. **Branch naming:** `type/agent/short-desc`
2. **Commit format:** Conventional Commits — `feat:`, `fix:`, `docs:`, `chore:`
3. **PR description:** Include what changed and why, test plan
4. **One concern per PR:** Do not bundle unrelated changes

---

## Code Standards

- Conventional Commits format
- Branch naming: `type/agent/short-desc`
- Never commit credentials, secrets, or runtime tokens
- Apache-2.0 license
