# DOCTRINE.md — hummbl-forge-engine

**Status:** v0.1
**Steward:** HUMMBL Research Institute

## 1. Thesis

hummbl-forge-engine is Game engine built in Rust for HUMMBL. The core bet is that this capability should be governed, auditable, and aligned with HUMMBL's operational standards.

## 2. Design principles

1. **Governed by default.** All operations follow HUMMBL governance protocols.
2. **No secrets.** Never commit credentials or runtime tokens.

## 3. Boundaries

hummbl-forge-engine focuses on its defined scope. It does not duplicate functionality from other HUMMBL repos.
